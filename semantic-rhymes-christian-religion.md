# 100 semantic rhymes — Christian religion

A **semantic rhyme** is a rhyming pair in which *both* words sit inside the topic's
semantic field. The sound connects them and so does the meaning.

`grace / place` is only a rhyme — one side is topical, the other is filler. `grace / race`
is a semantic rhyme, because "run the race" is itself Christian vocabulary. Every pair below
is chosen on that test: strike either word and you are still inside the religion.

**Rhyme column** — `perfect` means the stressed vowel and everything after it match.
`near` means the match is imperfect, usually a stress mismatch or an accent-dependent one.
`identical` means the two words are homophones carrying different senses.

## Notes on use

Pairs where **both** words are stressed content words — `womb / tomb`, `blood / flood`,
`grave / gave` — carry a line on their own. Pairs leaning on a function word or a proper
noun — `Son / done`, `Mark / ark` — need the rest of the line to do more work.

The Latinate set (63–70) rhymes so easily that it reads as filler if repeated. One per poem.

`sun / Son` (5) is an identical rhyme, not a true one. It works as wordplay and fails as
rhyme; some ears will hear it as a cheat.

Sixteen pairs recombine into larger rhyme families, which is where longer stanzas come from:

- **-Word** — Lord, Word, heard, sword, reward
- **-un/-one** — Son, sun, one, done, nun
- **-ame** — shame, flame, name, proclaim
- **-ell** — hell, fell, dwell, bell, cell
- **-ave** — grave, gave, save
- **-alm** — psalm, balm, palm, alms, psalms
- **-ost** — Ghost, host, boast
- **-ight** — light, sight, night
