Method

Measurement font string is the literal normal 400 22.6666667px "ChirpMeasure" with ctx.letterSpacing = "0px" and ctx.wordSpacing = "0px". Each sentence is measured whole, including its period. Ink scans render one line alone on a transparent canvas from integer x-origin 0, with the device ratio set explicitly via setTransform(dpr,0,0,dpr,0,0) rather than read from window.devicePixelRatio, so both DPR 1 and DPR 3 results are produced on any display. Any alpha above zero counts as ink; the reported value is the right edge of the rightmost inked column converted back to CSS px.

A pair passes only when both lines share the same actualBoundingBoxRight, the same rightmost ink at DPR 1, the same rightmost ink at DPR 3, and land on the target endpoint. Anything short of all four is a near miss and is shown with its exact deltas.

Writing constraints enforced on every candidate: one complete sentence ending in its rhyme word plus a period; no commas, emoji, hashtags, double spaces, or space before punctuation; no people's names. The chosen pair additionally has a token-type ratio of 1.0 — no word appears twice across both lines, compared case-insensitively with final punctuation stripped; pairings that fail that test are dropped before scoring. Syllable counts are approximate.
